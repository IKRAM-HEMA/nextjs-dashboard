# nextjs-dashboard

Next.js 14 (App Router) project with Clerk + NextAuth, Prisma, Tailwind and shadcn/ui.

## Agent skills

### Issue tracker

Issues live as GitHub issues on `IKRAM-HEMA/nextjs-dashboard` (`gh` CLI, or the GitHub MCP tools where `gh` is unavailable). See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` plus `docs/adr/` at the repo root, both created lazily. See `docs/agents/domain.md`.
